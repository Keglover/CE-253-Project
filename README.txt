# Getting started

	First and foremost, you will need to download the BIPIA repository, which can be found on github [here]{https://github.com/microsoft/BIPIA}. Afterwards, you can run the following command:

~~~
pip install -e /path/to/BIPIA
~~~

	If you do not run this command and do not have BIPIA installed, you will encounter errors with Python being unable to resolve the bipia class libraries used in the scripts. Externally, you could also run the fresh_setup.py script to do this automatically.
